# Delivery starts with an adhan-only prototype (APK #0)

The brief orders phase 1 (screens + prayer engine) before phase 2 (adhan). Because the adhan is the feature that failed before and the one the whole app depends on, we first ship APK #0: a minimal build that schedules an adhan two minutes ahead and must play with the phone locked and survive a reboot on the owner's real phone. Phase 1 starts only after it passes.
