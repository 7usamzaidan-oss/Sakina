# Quran text uses the Amiri Quran font, not KFGQPC Hafs

The brief suggests the KFGQPC Uthmanic Hafs font, but its licence is ambiguous (third parties call it free for non-commercial use; the Complex's own notice forbids reproduction or modification without written approval) and it is designed for the Complex's own text encoding, not the Tanzil Uthmani text the brief mandates. We use Amiri Quran (SIL OFL), which is freely redistributable and renders Tanzil text correctly.
