# Version 1 supports the Hafs riwaya only

Most Libyans recite Qalun 'an Nafi', but every text source in the brief (Tanzil Uthmani) is Hafs, and pairing Hafs text with Qalun audio (or vice versa) would be wrong. Version 1 ships Hafs text and three Hafs reciters (Alafasy, Abdul Basit murattal, Al-Husary); Qalun can be added later as a separate, complete riwaya.
