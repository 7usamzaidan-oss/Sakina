## 1. المهمة

أنت فريق تطوير متكامل (Mobile Developer، UI/UX، مختص مواقيت صلاة، QA).
ابنِ تطبيقاً إسلامياً حقيقياً جاهزاً للاستخدام باسم:

**SAKINA — سَكِينَة** | الشعار: «رفيقك في طريق الطاعة»

🆕 **المنصة المستهدفة الآن: Android فقط** (Android 8.0 / API 26 فما فوق). اجعل الكود قابلاً لدعم iOS لاحقاً، لكن لا تؤخّر Android بسبب iOS.

🆕 **المخرج الإلزامي الأول: ملف APK قابل للتثبيت مباشرة على هاتفي** (وليس AAB فقط، لأن AAB لا يُثبَّت يدوياً على الهاتف). سلّمني رابط تحميل APK في نهاية كل مرحلة مكتملة.

## 3. التقنية

- React Native + **Expo (أحدث SDK مستقر)** + TypeScript + Expo Router.
- SQLite (expo-sqlite) للتخزين المحلي، Zustand لإدارة الحالة.
- 🆕 **لا تستخدم Expo Go** للاختبار النهائي، لأن الإشعارات المخصصة والأذان في الخلفية لا تعمل فيه. استخدم **Development Build** و**EAS Build**.
- 🆕 لبناء APK استخدم ملف `eas.json` بملف تعريف (profile) باسم `preview` يحتوي:
  ```json
  { "build": { "preview": { "android": { "buildType": "apk" } },
               "production": { "android": { "buildType": "app-bundle" } } } }
  ```
  ثم: `eas build -p android --profile preview`
- 🆕 Package name: `com.sakina.app` — اسم التطبيق الظاهر: «سكينة».
- بنية Modular منظمة: `app/` (الشاشات) — `components/` — `services/` — `hooks/` — `stores/` — `data/` — `assets/`.
- لا تضع كل الكود في ملف واحد.

## 5. الشاشات (12 شاشة)

### 01 — الترحيب والإعداد الأولي
شعار سكينة، اختيار اللغة، طلب إذن الموقع (مع خيار إدخال المدينة يدوياً إن رفض المستخدم)، شرح مختصر للمزايا، اختيار طريقة الحساب.
🆕 في نفس الإعداد اطلب أذونات: الإشعارات، المنبهات الدقيقة (Exact Alarms)، واستثناء التطبيق من توفير البطارية — مع شرح لماذا كل إذن ضروري لعمل الأذان.

### 02 — الصفحة الرئيسية
المدينة، التاريخ الهجري والميلادي معاً مع **اسم اليوم**، الصلاة القادمة، عدّاد تنازلي حيّ، المواقيت الخمس + الشروق، الصلاة الحالية، اختصارات (القبلة، القرآن، الأذكار)، بطاقة ذكر اليوم.

### 03 — مواقيت الصلاة
الفجر، الشروق، الظهر، العصر، المغرب، العشاء — طريقة الحساب — المذهب (شافعي/حنفي للعصر) — تعديل يدوي بالدقائق لكل صلاة — وقت الإقامة لكل صلاة — جدول شهري.

### 04 — إعدادات الأذان
مؤذن لكل صلاة، أذان كامل أو تنبيه مختصر، مستوى الصوت، إشعار قبل الصلاة (5/10/15/30 دقيقة)، تنبيه عند دخول الوقت، اهتزاز، عدم إزعاج، زر اختبار صوت الأذان.
🆕 **زر «إيقاف الأذان»** يظهر في الإشعار نفسه أثناء التشغيل.
🆕 الضغط على زر خفض الصوت يوقف الأذان.

### 05 — القبلة
بوصلة حقيقية، اتجاه الكعبة، الدرجة، المسافة إلى مكة، شاشة معايرة (حركة رقم 8)، رسالة واضحة إن لم يتوفر مستشعر مغناطيسي.
🆕 **استخدم الشمال الحقيقي (True North) وليس المغناطيسي**؛ صحّح الانحراف المغناطيسي (Magnetic Declination) حسب موقع المستخدم، وإلا سيخطئ الاتجاه بعدة درجات.
🆕 اهتزاز خفيف وتغيّر لون عند ضبط الاتجاه على القبلة (±3 درجات).
🆕 إحداثيات الكعبة: 21.422487, 39.826206.

### 06 — القرآن الكريم
مصحف، فهرس السور، الأجزاء والأحزاب، البحث، العلامات المرجعية، آخر موضع قراءة، وضع ليلي، حجم الخط، الاستماع، التحميل للاستماع دون إنترنت.
🆕 **مصدر النص (إلزامي)**: نص Tanzil.net برواية حفص (Uthmani)، يُضمَّن داخل التطبيق كملف محلي ويعمل بدون إنترنت. **ممنوع توليد أي آية بالذكاء الاصطناعي.**
🆕 **مصدر التلاوات**: everyayah.com أو mp3quran.net (روابط مباشرة لكل قارئ)، مع اختيار 3 قرّاء على الأقل.

### 07 — الأذكار والتسبيح
أذكار الصباح، المساء، النوم، الاستيقاظ، بعد الصلاة — مسبحة إلكترونية بعدّاد مع اهتزاز — حفظ التقدم.
🆕 **مصدر الأذكار**: كتاب «حصن المسلم» للقحطاني، مع ذكر المرجع (البخاري، مسلم...) وعدد التكرار لكل ذكر. يُضمَّن كملف JSON محلي.

### 08 — متابعة الصلاة
تسجيل الصلوات (أُدّيت / فاتت / قضاء)، إحصائيات أسبوعية وشهرية برسوم بيانية، السجل، تذكيرات اختيارية. البيانات تبقى على الهاتف فقط.

### 09 — التقويم
الشهر الهجري والميلادي معاً، المناسبات (رمضان، العيدان، عرفة، عاشوراء، المولد، الإسراء والمعراج...)، التنقل بين الأشهر، تعديل التاريخ الهجري ±1 أو ±2 يوم.
🆕 الحساب الافتراضي: تقويم أم القرى، مع عدّ تنازلي لرمضان.

### 10 — المساجد القريبة
قائمة المساجد مع المسافة، الخريطة، البحث، فتح الاتجاهات في خرائط Google.
🆕 **مصدر البيانات: OpenStreetMap عبر Overpass API (مجاني، بدون مفتاح)**، والخريطة عبر react-native-maps أو مكتبة OSM. لا تستخدم Google Places لأنه مدفوع.
🆕 أوقات الإقامة للمساجد غير متوفرة في أي مصدر موثوق لليبيا، لذا: اجعل المستخدم يُدخل أوقات الإقامة لمسجده المفضّل يدوياً.

### 11 — منبّه الفجر
تنبيه قبل الفجر بمدة يختارها المستخدم، نغمة، أيام التكرار، استيقاظ تدريجي (رفع الصوت تدريجياً)، غفوة.
🆕 يجب أن يعمل كمنبّه حقيقي يُظهر **شاشة كاملة فوق شاشة القفل** (Full-Screen Intent) حتى لو كان الهاتف مقفلاً.

### 12 — الإعدادات
اللغة، المظهر، الموقع، طرق الحساب، الإشعارات، إدارة التنزيلات (حجم الملفات وحذفها)، نسخ احتياطي (تصدير/استيراد ملف JSON)، الخصوصية، حول التطبيق.
🆕 قسم «تشخيص الإشعارات»: يعرض حالة كل إذن (مفعّل/غير مفعّل) مع زر يفتح إعدادات النظام مباشرة لتفعيله.

## 6. محرك مواقيت الصلاة

🆕 **استخدم مكتبة `adhan` (adhan-js) المعروفة والمختبرة** بدلاً من كتابة الحسابات من الصفر، وغلّفها في `services/prayerTimes.ts`.

يجب أن يدعم:
- كل طرق الحساب المعروفة (رابطة العالم الإسلامي، أم القرى، الهيئة المصرية، كراتشي، ISNA، دبي، قطر، الكويت...).
- 🆕 **الإعداد الافتراضي لليبيا: الهيئة المصرية العامة للمساحة** (الفجر 19.5°، العشاء 17.5°)، مع المذهب الشافعي/المالكي للعصر.
- المذهب الحنفي للعصر، خطوط العرض العالية، المناطق الزمنية، التوقيت الصيفي، التعديل اليدوي بالدقائق.
- إعادة الحساب تلقائياً عند تغيير الموقع.
- 🆕 الموقع الافتراضي إن لم يتوفر GPS: **طرابلس، ليبيا** (32.8872, 13.1913).
- 🆕 **اختبار إلزامي**: قارن نتائج طرابلس لـ 7 أيام مع تقويم الهيئة العامة للأوقاف الليبية أو موقع موثوق، والفرق المقبول ±2 دقيقة. ضع نتائج المقارنة في تقرير الاختبارات.
- أظهر للمستخدم طريقة الحساب المستخدمة في شاشة المواقيت.

## 7. الأذان والإشعارات 🆕 (أهم قسم — أعِد كتابته بالكامل)

هذا القسم هو سبب فشل النسخة السابقة من التطبيق (الإشعارات لم تعمل). التزم بالتالي حرفياً:

1. **لا تعتمد على `expo-notifications` وحدها لتشغيل الأذان الكامل.** استخدم **Notifee** (`@notifee/react-native`) مع Config Plugin، أو Native Module بـ Kotlin.
2. الجدولة بـ **`AlarmManager.setExactAndAllowWhileIdle` / `setAlarmClock`** حتى يعمل الأذان في وضع Doze والهاتف مقفل.
3. تشغيل الأذان الكامل عبر **Foreground Service** من نوع `mediaPlayback` مع إشعار فيه زر «إيقاف».
4. الأذونات في `AndroidManifest`:
   `POST_NOTIFICATIONS`, `SCHEDULE_EXACT_ALARM`, `USE_EXACT_ALARM`, `RECEIVE_BOOT_COMPLETED`, `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_MEDIA_PLAYBACK`, `WAKE_LOCK`, `USE_FULL_SCREEN_INTENT`, `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS`, `VIBRATE`.
5. **BroadcastReceiver لـ `BOOT_COMPLETED`** يعيد جدولة الأذان بعد إعادة تشغيل الهاتف.
6. جدولة مواقيت **7 أيام قادمة** دائماً، وإعادة الجدولة عند: فتح التطبيق، تغيير الإعدادات، تغيير الموقع، منتصف الليل.
7. **قناة إشعار (Notification Channel) منفصلة لكل مؤذن**، لأن Android لا يسمح بتغيير صوت القناة بعد إنشائها.
8. شاشة تطلب من المستخدم استثناء التطبيق من **توفير البطارية**، مع تعليمات خاصة لهواتف Samsung وXiaomi وHuawei وOppo (هذه الهواتف تقتل التطبيقات في الخلفية).
9. **اختبار إلزامي**: جدول أذاناً بعد دقيقتين، اقفل الهاتف، وتأكد أنه يعمل. ثم أعد تشغيل الهاتف وتأكد أن الأذان التالي ما زال مجدولاً.

## 9. العمل بدون إنترنت
يعمل بدون إنترنت: المواقيت، القبلة، الأذكار، نص القرآن كاملاً، سجل الصلاة، الإعدادات، الأذان.
يحتاج إنترنت فقط: المساجد القريبة، تحميل التلاوات.
لا تجعل الإنترنت شرطاً لفتح التطبيق.

## 10. الخصوصية
لا حسابات، لا إعلانات، لا تتبّع، لا Analytics. الموقع يُستخدم محلياً فقط. اذكر في «حول التطبيق» أي خدمة خارجية مستخدمة (Overpass، everyayah).

## 11. معايير الجودة
لا أزرار لا تعمل، لا شاشات فارغة، لا بيانات وهمية، لا أخطاء RTL، لا تجاهل للأخطاء. كل زر له وظيفة حقيقية.
